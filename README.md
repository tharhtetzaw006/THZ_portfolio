## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/tharhtetzaw006/THZ_portfolio.git
```

Go to the project directory:

```bash
cd THZ_portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Start production server:

```bash
npm start
```
